# Search Immersion

Search Immersion は、Google の検索画面と新しいタブをスマートディスプレイ風のレイアウトへ変更する Chromium 拡張機能です。時計、天気、ニュース、メディア情報などを一つの画面にまとめて表示します。

## 主な機能

- **スマートディスプレイ UI**：時計、天気、ニュースなどをカード形式で表示します。
- **メディア連携**：対応する YouTube / Spotify の再生情報を検出すると、アルバムアートなどを使ったプレイヤー表示へ切り替えます。
- **Zen モード**：時計やカードを隠し、検索 UI を中心に表示します。
- **表示位置の微調整**：常時表示で同じ画素を使い続けないよう、画面要素を定期的にわずかに移動します。
- **表示設定**：背景の明るさ、カードの透明度、時計フォントなどを変更できます。
- **多言語 UI**：日本語、英語、韓国語、中国語の表示リソースを含みます。

## インストール

現在は Chrome ウェブストアでは配布していないため、開発者モードで読み込みます。

1. このリポジトリを ZIP で取得するか clone し、ファイルを展開します。
2. Chromium 系ブラウザで `chrome://extensions` を開きます。
3. **デベロッパーモード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**を選び、リポジトリのフォルダを指定します。

Google のトップページまたは新しいタブを開くと Search Immersion の UI が表示されます。設定は画面内の設定ボタンから変更できます。

## 対応環境

Chromium 系ブラウザを対象としています。macOS、Windows、Linux での利用を想定していますが、OS やブラウザによってフォントやレイアウトに差が出る場合があります。

## 外部サービスとデータ

Search Immersion は表示内容を構成するため、機能に応じて外部サービスへリクエストを送ります。

- **Open-Meteo**：天気情報の取得。天気機能では、検索に必要な位置情報または座標がリクエストに含まれる場合があります。
- **Unsplash**：背景画像などの取得。
- **YouTube / Spotify**：ブラウザ内で開いている対応ページのメディア状態を利用する機能があります。

拡張機能独自のサーバーへ閲覧履歴を収集・保存することを目的とした実装ではありません。ただし、外部サービスへ送信される情報と各サービス側の取り扱いは、それぞれのサービスの仕様・ポリシーに従います。

## 注意事項

Search Immersion は Google、YouTube、Spotify、Open-Meteo、Unsplash の公式製品ではありません。各 Web サービスの DOM、API、認証、配信仕様などが変更された場合、一部機能が動作しなくなる可能性があります。
